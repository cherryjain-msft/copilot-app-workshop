# GitHub Copilot App workshop

**Hands-on companion:** [the workshop guide](https://cherryjain-msft.github.io/copilot-app-workshop/workshop/index.html) has copy-ready prompts and expected results for the exercises that use the three `dealer-*` repositories and the demo assets in this repository.

## Quick start

1. **Fork this repository.** Click **Fork**, choose your GitHub account, then click **Create fork**.
2. **Open your fork in Copilot.** Open the [GitHub Copilot app](https://github.com/github/app), sign in, add your fork as a repository, and start a session.
3. **Set up the Projects exercise.** Fork [dealer-appointments-api](https://github.com/cherryjain-msft/dealer-appointments-api), [dealer-customer-portal](https://github.com/cherryjain-msft/dealer-customer-portal), and [dealer-help-center](https://github.com/cherryjain-msft/dealer-help-center). Create a Project in Copilot and add your three forks.
4. **Try one feature at a time.** Follow the workshop guide in order: **Projects → Automations → Jira Workbench → Parallel sessions → Copilot Fusion**. For each lesson, follow its setup, copy a prompt, replace sample repository names with your forks, and check the expected result before continuing.
